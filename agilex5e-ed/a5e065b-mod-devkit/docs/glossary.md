# 4Kp60 SDI-based Genlock HDR Video Pipeline System Example Design for Agilex™ 5 Devices — Acronyms and Terminology

| **Term** | **Definition** |
| :------: | :-------------------------------------------------------- |

| BNC      | Bayonet Neill–Concelman coaxial connector |
| BPS      | Bits per symbol |
| BT.709   | ITU-R Recommendation BT.709 (SDR HDTV colorimetry) |
| BT.1886  | ITU-R Recommendation BT.1886 (SDR reference electro-optical transfer function) |
| BT.2100  | ITU-R Recommendation BT.2100 (HDR production, including PQ and HLG) |
| CDC      | Clock domain crossing |
| CRS      | Chroma Resampler |
| CSC      | Color Space Converter |
| CSR      | Control and status registers |
| EOTF     | Electro-optical transfer function |
| ESD      | Electrostatic discharge |
| FMC      | FPGA mezzanine card |
| FPGA     | Field-programmable gate array |
| FPS      | Frames per second |
| Genlock  | Generator locking. Output timing is locked to a reference. |
| GTS      | Generic transceiver subsystem |
| GUI      | Graphical user interface |
| HDR      | High dynamic range |
| HEX      | Hexadecimal memory initialization file |
| HLG      | Hybrid Log-Gamma (ITU-R BT.2100) |
| HW       | Hardware |
| I/O      | Input/output |
| IP       | Intellectual property (hardware) |
| JTAG     | Joint Test Action Group (IEEE 1149.1 test and debug interface) |
| LUT      | Lookup table |
| Nios® V  | Altera RISC-V soft processor |
| OETF     | Opto-electronic transfer function |
| OOTF     | Opto-optical transfer function |
| PIP      | Pixels in parallel |
| PLL      | Phase-locked loop |
| PQ       | Perceptual Quantizer (ITU-R BT.2100 / SMPTE ST 2084) |
| QPF      | Quartus Prime project file |
| QSF      | Quartus Prime settings file |
| RGB      | Red, green, and blue |
| RTL      | Register transfer level |
| RX       | Receive |
| SDI      | Serial digital interface |
| SDR      | Standard dynamic range |
| S-Log3   | Sony logarithmic HDR transfer function |
| SOF      | SRAM Object File (FPGA programming file) |
| SW       | Software |
| TPG      | Test Pattern Generator |
| TX       | Transmit |
| UART     | Universal asynchronous receiver-transmitter |
| UHD      | Ultra-high definition |
| VDS      | Visual Designer Studio |
| VVP      | Video and Vision Processing |
